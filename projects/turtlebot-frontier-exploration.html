TurtleBot Frontier Exploration (ROS2)

AA274A: Principles of Robot Autonomy I | 09/2024 – 12/2024

Overview

Developed an autonomous frontier exploration system for a TurtleBot using ROS2, focusing on motion control, localization, and navigation to enable exploration in unknown environments.

My Role

  • Motion control: designed an LQR-based trajectory control system, integrating spline fitting for smooth path generation and optimized state control.
  • Localization: built a multi-sensor fusion pipeline using LiDAR and odometry, achieving 82% mapping coverage with EKF-based pose estimation.
  • Navigation: implemented rule-based frontier exploration to dynamically select target positions, optimized A* path planning, and designed sign detection for safer exploration.

Outcome & Impact

  • Enhanced trajectory tracking accuracy by optimizing the LQR control strategy for smooth, stable motion.
  • Achieved 82% mapping coverage in unknown environments, significantly improving navigation capabilities.
  • Improved navigation efficiency and safety, enabling the robot to autonomously explore complex environments with a higher task success rate.
